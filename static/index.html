One controlled comparison

01

Separate the cases

120 training, 40 validation, and 80 test cases. Each simulated patient appears in one split only.

02

Fit the classifier

A fixed toy feature map creates three numbers per patch. A logistic classifier learns from training cases. Validation selects the decision threshold.

03

Change the sampling

Random sampling selects anywhere in the grid. Spatial sampling selects one patch from each equal-area region. Both use the same patch count.

04

Compare reliability

Repeat sampling with the model fixed. Use the same predictions for both review rules. Report errors at matched review rates.

What works in this demo

  • Reproducible simulated cases and separate data splits
  • A fitted lightweight classifier
  • Repeated patch sampling with matched budgets
  • Review flags, accuracy intervals, AUROC, and calibration
  • Downloadable case predictions and experiment settings

What the research still needs

  • Real H&E slides with verified ER labels
  • Quality control and a frozen pathology encoder
  • Patient-level feature aggregation and external evaluation
  • Evidence that disagreement adds value beyond confidence

Lower variance does not prove a prediction is correct. Simulated results do not establish clinical benefit or novelty.
